# Tracera: VERITAS-024

> **AI-Powered Digital Evidence Integrity & Fraud Investigation Platform**

VERITAS-024 is an evidence preservation, forensic analysis, and fraud investigation platform built under strict epistemic integrity principles.

## Epistemic Hierarchy
Every piece of information carries exactly one epistemic classification:
- **`VERIFIED_FACT`**: Computed deterministically (SHA-256 hashes, file byte length, raw file headers).
- **`EXTRACTED_OBSERVATION`**: Extracted directly from document content via parsers, OCR, or Gemini Vision. Subject to OCR/reading variance.
- **`TAMPER_INDICATOR`**: Statistical or structural anomalies (Error Level Analysis hotspots, PDF incremental saves, DKIM mismatches). Never treated as absolute proof.
- **`AI_INFERENCE`**: Synthesis, timeline correlations, or narrative explanations generated by Gemini. Marked with required human review warnings.

> **Core Principle**: AI suggests. A human decides. The platform never declares guilt, authenticity, or fraud.

## Quickstart Guide

### 1. Backend Service
```bash
cd veritas-024/backend
python -m pip install -r requirements.txt
cp .env.example .env
# Optionally add your GOOGLE_API_KEY in .env
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
- API Documentation (Swagger): [http://localhost:8000/docs](http://localhost:8000/docs)
- Case Report Docket: [http://localhost:8000/api/report](http://localhost:8000/api/report)

### 2. Frontend Application
```bash
cd veritas-024/frontend
npm install
npm run dev
```
- Web Application: [http://localhost:3000](http://localhost:3000)

## Demo Script (RF-2291 Investigation)
1. Open the workbench at `http://localhost:3000`.
2. Click **"Load Demo Case"** to seed the 6 synthetic test artifacts.
3. Review the **Vault Pane** for SHA-256 hashes, duplicate detection, and tamper flags.
4. Use the **Inspector Pane** to examine extracted claims, source references, and ELA heatmaps.
5. Explore the **Timeline & Graph Pane** to trace chronological sequence violations and run shortest-path queries.
6. Review discrepancies in the **Audit Drawer**, accept/reject findings, and click **"Verify Audit Chain"** to confirm cryptographic integrity.
7. Click **"Export Report"** for a print-ready investigation docket.
